# 팀 연동 안내 — 내부 원본은 별도 보관

이 경로는 과거 실행 환경과 팀 전용 연결 정보를 참조하던 문서의 호환 안내입니다. 원문은 공개 저장소에서 제외하고 저장소 밖의 보관본으로 유지합니다.

공개 가능한 로컬 실행 절차는 [실행·재현 문서](portfolio/07-reproduction-and-limitations.md), 재현 패키지 안내는 [패키지 README](../repro-package/NEXUS-WORK-REPRO-2026-11-09/README.md)를 참고하세요. 내부 운영 주소·계정·토큰은 이 저장소에 기록하지 않습니다.
