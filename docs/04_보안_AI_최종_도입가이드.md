1. **[사전 감사]** Cloudflare `security-audit-skill`을 통한 소스코드 전수 검사 (오탐 0% 적대적 검증)

## 1. 아키텍처 개요 및 하드웨어 환경 최적화

현재 `nexus-work`는 Flask, Docker(MySQL), 보안 로그(`logs/security.jsonl`), 메타데이터 XDR(`app/ai_xdr.py`)로 구성된 사내 업무 포털 겸 보안 방어전 시스템입니다.

개발 환경이 **"외장 GPU가 없는 내장 그래픽 PC"**이므로, 로컬 자원을 소모하는 방식을 배제하고 **Cloudflare의 에이전트 감사 스킬**과 **엔비디아 클라우드 NIM 인프라**를 조합하여 **"내 컴퓨터 부하 0, 비용 0원, 최고 사양 방어 체계"**를 구축합니다.

## 2. [심층 분석 1] Cloudflare `security-audit-skill` (사전 코드 취약점 전수 감사)

> **공식 저장소:** [https://github.com/cloudflare/security-audit-skill](https://github.com/cloudflare/security-audit-skill)  
> **라이선스:** MIT (완전 무료 오픈소스) | **하드웨어 요구:** GPU 불필요 (내장 그래픽 PC 100% 동작)

### ① 왜 기존 정적 분석기(SonarQube 등)나 일반 AI 대신 이 도구를 쓰는가?
일반적인 AI 코드 스캐너는 수십 개의 취약점을 쏟아내지만 대부분 **"실제로는 공격 불가능한 가짜 취약점(False Positive, 환각)"**이어서 개발자의 시간을 크게 낭비시킵니다.  
Cloudflare의 이 스킬은 취약점 후보를 찾은 뒤, **독립된 서브에이전트가 이를 반박(Disprove)하는 적대적 검증(Adversarial Validation)**을 거쳐 **실제 작동하는 취약점만 엄선**합니다.

### ② 6단계 감사 파이프라인 (The 6-Phase Pipeline)
1. **Phase 1: Reconnaissance (정찰)**
   - `nexus-work` 전체 디렉터리, Flask 라우트, 미들웨어, DB 신뢰 경계(Trust Boundary) 맵핑
2. **Phase 2: Coverage-Led Hunting (공격 클래스별 사냥)**
   - 인증/인가(BOLA, IDOR), SQL 인젝션, 파일 업로드 취약점, AI 프롬프트 인젝션 벡터 집중 탐색
3. **Phase 3: Candidate Validation (후보 검증)**
   - 발견된 후보 취약점이 실제 코드 흐름 상에서 트리거 가능한지 격리된 로컬 테스트로 검증
4. **Phase 4: Independent Record Verification (독립 교차 검증 - 핵심 ⭐)**
   - 취약점을 찾은 에이전트와 **완전히 분리된 독립 서브에이전트**를 실행하여 "이 취약점이 성립하지 않는 이유"를 찾아내도록 공격적 반박 진행 → 반박에 성공한 가짜 취약점은 자동 탈락
5. **Phase 5: Structured Output Generation (정형화 보고)**
   - 살아남은 진짜 취약점만 CWE, CVSS 점수, 재현 코드(PoC), 권장 수정(Patch) 코드로 포맷팅
6. **Phase 6: Defensive Reporting (최종 리포트)**
   - 최종 결과를 `VULN-FINDINGS.md` 및 `VULN-FINDINGS.json` 규격으로 완벽하게 출력

### ③ `nexus-work` 핵심 점검 타깃
* **첨부파일 무제한 정책 점검:** `app/attachments.py`의 무작위 파일명 저장 및 경로 격리 로직이 Path Traversal이나 RCE로 뚫릴 수 있는지 정밀 추적
* **권한 우회(BOLA/IDOR) 점검:** 일반 사원이 기밀 문서(`nexus_conf`), 타인 급여, 전자결재 순차 결재선을 변조할 수 있는지 추적
* **사내 AI 탈옥 점검:** `app/ai.py`의 RAG 컨텍스트 주입 과정에서 시스템 프롬프트가 무력화될 수 있는지 검사

### ④ 설치 및 실행 방법
AI 코딩 에이전트 환경에서 CLI 명령어로 즉시 추가할 수 있습니다:
```bash
# 에이전트에 Cloudflare 보안 감사 스킬 추가 (무료)
npx skills add https://github.com/cloudflare/security-audit-skill --skill security-audit
```
이후 에이전트에게 **"nexus-work 소스코드 전체에 대해 security-audit을 실행하고 VULN-FINDINGS.md를 갱신해줘"**라고 지시하면 6단계 감사가 자동 실행됩니다.

## 3. [심층 분석 2] NVIDIA Llama-3.1-Nemotron-70B NIM (실시간 XDR 관제)

> **공식 사이트:** [https://build.nvidia.com](https://build.nvidia.com)  
> **비용:** 무료 1,000 크레딧 제공 (약 10,000 ~ 20,000회 무료 API 호출)  
> **하드웨어 요구:** GPU 불필요 (엔비디아 클라우드 서버 연산)

### ① 선정 이유
* **로컬 부하 0:** 내장 그래픽 PC에서 70B 모델을 직접 돌리면 컴퓨터가 멈추지만, NIM API는 인터넷 호출이므로 내 PC 메모리 점유율이 0%입니다.
* **복합 공격 체인(Attack Chain) 추론:**
  * 기존 단일 룰: "R1 로그인 5회 실패" → 단순 경고
  * Nemotron-70B: "IP 192.168.1.50이 R1 무차별 대입 실패 후, 탈취한 세션으로 R5 관리자 권한 및 R8 기밀 결재선 변조를 연속 시도함 → **공격 체인 확인: 즉시 MALICIOUS 판정 및 영구 차단 권고**"

### ② `nexus-work` 적용 설정 (`.env`)
`app/ai_xdr.py`는 이미 OpenAI 호환 규격으로 작성되어 있어 아래 설정만 넣으면 즉시 교체됩니다:
```ini
XDR_AI_PROVIDER=nvidia
NVIDIA_API_KEY=nvapi-your-key-here
NVIDIA_MODEL=nvidia/llama-3.1-nemotron-70b-instruct
NVIDIA_BASE_URL=https://integrate.api.nvidia.com/v1
```

## 4. [심층 분석 3] NVIDIA NeMo Guardrails (사내 AI 챗봇 보호)

> **라이선스:** Apache 2.0 (100% 영구 무료 오픈소스) | **구동 환경:** CPU 파이썬 라이브러리

* **역할:** 사내 그룹웨어 AI 챗봇(`app/ai.py`) 앞단에서 프롬프트 인젝션 및 기밀 데이터 유출 방어
* **주요 정책:**
  * **Colang 규칙 강제:** 시스템 프롬프트 무시 명령이나 사칭 프롬프트를 LLM 도달 전에 차단
  * **민감 토큰 마스킹:** AI 응답에 사내 토큰(`nxapi_...`)이나 기밀 식별자(`NXC-...`)가 포함될 경우 실시간 마스킹
